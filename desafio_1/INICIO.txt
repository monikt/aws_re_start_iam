# ❌ ERRORES COMUNES
# ==============================================================================

"ModuleNotFoundError: boto3"
→ pip install -r requirements.txt

"Unable to locate credentials"
→ Editar .env con AWS_ACCESS_KEY_ID y AWS_SECRET_ACCESS_KEY

"Email refused"
→ Para Gmail: Usar App Password (NO contraseña)
→ https://myaccount.google.com/apppasswords

"NoSuchBucket"
→ S3_BUCKET_NAME debe ser único globalmente
→ No puede tener mayúsculas ni guiones bajos

Ver más errores en: RESOLUCION_RAPIDA.md
